# TryHackMe IL 🇮🇱

פלטפורמת לימוד סייבר בעברית, בהשראת חוויית למידה מעשית עם מסלולים, חדרים, XP ותרגול אינטראקטיבי בטוח.

## מה יש בגרסה הראשונה
- ממשק RTL מלא בעברית
- מסלולי לימוד
- חדרי תרגול עם חיפוש וסינון
- XP, רמות והתקדמות הנשמרים ב־LocalStorage
- Leaderboard לדוגמה
- Safe Terminal מקומי בדפדפן בלבד
- Responsive למחשב וטלפון
- מוכן לאחסון כאתר סטטי ב־GitHub Pages

## מבנה
- `index.html`
- `css/style.css`
- `js/app.js`
- `assets/favicon.svg`

## בטיחות
התרגולים בגרסה זו אינם תוקפים שום מערכת אמיתית. הטרמינל הוא סימולטור מקומי בלבד.

## המשך מומלץ
בשלב הבא אפשר לחבר Supabase עבור משתמשים אמיתיים, התחברות, שמירת XP בענן, Leaderboard חי, אדמין וחדרים דינמיים.
